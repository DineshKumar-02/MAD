# Experiment 7: Develop a Simple Shopping Application

## Aim
To develop a simple shopping application that maintains product inventory, allows adding items to a shopping cart, updates quantities, and calculates the total payable amount.

## Features
- **Product Inventory Model**: `Product(id, name, price, description, icon)`
- **Dynamic Cart Management**:
  - Add items to cart with live quantity badge
  - Increment / decrement quantity within cart
  - Automatic removal when quantity drops to zero
- **Financial Calculations**: Real-time subtotal and grand total summation
- **Order Placement**: Interactive checkout confirmation modal

## Files
- `lib/main.dart`: Complete interactive Flutter e-commerce shopping cart app.
- `kotlin/ShoppingCart.kt`: Kotlin console implementation matching the lab manual.

## Result
The simple shopping application has been developed and executed successfully.
