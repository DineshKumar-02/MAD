# Experiment 2: Develop an Application that Uses Widgets, GUI Components, Fonts, and Colors

## Aim
To develop an application that utilizes basic and advanced UI Widgets, GUI components, Fonts, and Colors.

## Components Implemented
1. **Widgets & Layouts**:
   - `Scaffold`, `AppBar`, `Column`, `Row`, `SingleChildScrollView`, `Card`, `Container`
2. **GUI Input Components**:
   - `TextField` with InputDecoration (label, hint, border, prefix icon)
   - `DropdownButton` (ComboBox) with selectable option list
   - `ElevatedButton` and `OutlinedButton` with click handlers
   - `Switch` and `Slider` controls
3. **Fonts & Typography**:
   - Custom font families (`serif`, `sans-serif`)
   - Font sizes dynamically controlled with slider
   - Font weight toggle (Bold / Normal) and Font styles (Italic)
4. **Colors**:
   - Background color palette changer
   - Hex color codes (`#F0F0F0`, `#E3F2FD`, etc.) matching the manual specifications

## Files
- `lib/main.dart`: Complete Flutter implementation matching the mobile UI shown in lab manual.
- `kotlin/MyApp.kt`: The Kotlin/JavaFX program from page 8-10 of the manual.

## Result
The application using Widgets, GUI components, Fonts, and Colors has been developed and executed successfully.
