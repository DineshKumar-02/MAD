# Experiment 3: Develop a Native Calculator Application

## Aim
To develop a native calculator application supporting standard arithmetic operations (+, -, *, /) and dynamic UI updates.

## Features
- **4-Column Grid Design**: Matches native Android calculator layout and screenshot in lab manual.
- **Arithmetic Logic**: Handles addition, subtraction, multiplication, division, decimals, and percentage.
- **State Handling**: Backspace/delete (`D`), clear all (`C`), single-dot validation, and division-by-zero protection.
- **Dark Theme UI**: High-contrast theme with orange operator buttons and white typography.

## Files
- `lib/main.dart`: Complete, standalone Flutter calculator application (ready to run on Android, Web, or Windows).
- `android_native/activity_main.xml`: XML layout for Android Studio.
- `android_native/MainActivity.kt`: Native Android Kotlin implementation with ExpressionBuilder.

## Result
The native calculator application has been developed and executed successfully.
